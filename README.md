# dsh-collab

Human collaboration rooms for one host-side DSH Agent session.

The architecture and incremental implementation plan live in [design.md](./design.md). P0 currently contains only the in-memory domain core and fake Agent boundary; network, UI, persistence adapters, and DSH runtime integration are later phases.

## Commands

```sh
pnpm install
pnpm test
pnpm typecheck
```
